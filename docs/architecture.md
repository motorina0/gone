# Architecture

`WorldState` is authoritative. A 30 Hz fixed-step clock currently updates only player movement; Phaser rendering projects that state without owning it. `GameScene` does not construct or update guard, patrol, detection, observation, interaction, or mission systems in exploration mode. The dormant generic modules remain isolated for possible future phases.

Every public location manifest declares `mode: "exploration"`, one player entity, and no patrol resources. Content behavior and geometry come from external JSON/SVG resources, never location-specific branches in generic systems. Restart clears movement orders before reconstructing canonical state.

The visual stack is a camera-aligned extended backdrop, a baked 2× material-rich WebP background displayed on the canonical 960×640 stage, detail overlay, projected character/route markers, then foreground occlusion. Vatra's primary editable source is a Gone-only Blender scene with five orthographic cameras and aligned extended backdrops, beauty, depth, and transparent building/foliage masks; four external Gone finish plates provide the tactical beauty pixels. The deterministic bake feathers each finished center into the matching extended Blender backdrop and derives its transparent foreground colors from the same plate plus the Blender mask, preventing double-image occlusion. SVG projections remain deterministic editable fallbacks. All gameplay layers align through the same per-location projection resource. Tactical cameras expose exactly five semantic levels. For each projection and usable viewport, level 1 is solved against the exact convex footprint so every viewport corner remains on authored map; level 5 is derived from canonical character height and fills 94% of usable height; the intermediate levels form a geometric sequence. Focus may be remembered per view, but the level is global to the game. SAT uses a separate whole-map solution. Agent selection, route, destination, and invalid-order overlays remain anchored to projected world coordinates, while every overlay radius, offset, and stroke is converted from fixed screen pixels through the active camera zoom.

Boot loads only the preferred view plus the compact data-driven operative atlas. Other backdrop/background/detail/occlusion layer sets are decoded on first use and retained in Phaser's texture cache. At level 5, only the 3072×3840 close-up WebP sheet for the operative's current facing is fetched; another direction is loaded only if first needed. The manifest declares both frame geometries, the measured visible silhouette heights, eight directions, and idle/walk/run frame indexes.

Navigation loads the active location's external `navigation/walkable.json`. Polygon unions describe traversable surfaces and elevations; blockers from navigation JSON and blocking environment props are applied afterward. A deterministic eight-neighbour A* route cannot cut blocked corners, and line-of-sight smoothing never leaves the authored surface.
