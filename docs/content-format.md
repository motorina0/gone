# Content format

`public/content/index.json` is the registry. Each manifest resolves all paths relative to itself and references independently editable JSON/SVG resources. Every resource has `id`, `schemaVersion`, and a human-readable name where appropriate. Schemas in `public/content/schemas` are validated by `tools/validate-content.ts`. Keep IDs stable and paths case-sensitive.

Exploration manifests must list exactly one player entity and no patrols. `environment.json` stores canonical world-space atmosphere, surfaces, landmarks, trees, and street furniture. Static props with `blocksMovement: true` contribute blockers using their dimensions and rotation. `navigation/walkable.json` stores explicit world-space polygon unions with elevation; it is authoritative for destinations and paths. Current traversable areas are ground-level because ramp and stair transitions are deferred; visual elevated structures are not silently treated as ground crossings. `tools/generate-placeholder-views.ts` projects the same environment data into all five SVG `sourceViews`, resolves external raster materials from `public/content/materials`, and bakes the five manifest `views` as self-contained 2× WebPs. Detail and occlusion resources remain independently replaceable.
