# Content format

`public/content/index.json` is the registry. Each manifest resolves all paths relative to itself and references independently editable JSON/SVG resources. Every resource has `id`, `schemaVersion`, and a human-readable name where appropriate. Schemas in `public/content/schemas` are validated by `tools/validate-content.ts`. Keep IDs stable and paths case-sensitive.

Exploration manifests must list exactly one player entity and no patrols. `environment.json` stores canonical world-space atmosphere, surfaces, landmarks, trees, and street furniture. Static props with `blocksMovement: true` contribute blockers using their dimensions and rotation. `navigation/walkable.json` stores explicit world-space polygon unions with elevation; it is authoritative for destinations and paths. Current traversable areas are ground-level because ramp and stair transitions are deferred; visual elevated structures are not silently treated as ground crossings.

The five `views`, `sourceViews`, detail overlays, and occlusion masks share the manifest's ordered projection list. Optional `depthMaps` use the same ordering. `agentAtlas` and `agentAnimation` declare frame dimensions, eight direction rows, motion columns, and frame rates without embedding character configuration in the scene code. `tools/generate-placeholder-views.ts` creates deterministic editable SVG fallbacks; Vatra's Blender source produces its final five WebPs and depth outputs. Every resource remains independently replaceable.
